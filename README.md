Titanic EDA – Project

Exploratory Data Analysis on the Titanic dataset, covering survival patterns by gender, class, fare, family size, and embarkation port. Includes feature engineering (Family Size, Is Alone, Age Group, Fare Category), 10 business-question visualizations, a correlation heatmap, statistical analysis, and business recommendations.

Files:
Titanic_EDA.ipynb — full analysis notebook
Titanic_EDA_Report.pdf — PDF export of the notebook
Cleaned_Titanic.csv — cleaned dataset used for analysis
